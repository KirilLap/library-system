# CLAUDE.md

## Проект
Веб-система управления мобильной библиотекой на Django.
Библиотекари готовят партии книг в офисе и доставляют в махалли/организации.
В библиопунктах персонала нет. Весь учёт — в офисе до и после доставки.

## Запуск
```
source venv/bin/activate  # или venv\Scripts\activate.bat на Windows
python manage.py runserver
```

## Стек
- Django 5, Python 3.11, SQLite (разработка)
- Bootstrap 5 CDN, без сборки фронтенда
- pymarc, ReportLab (PDF), python-docx (Word), qrcode[pil]

## Структура URL
- /admin-panel/           — кабинет библиотекаря
- /catalog/               — публичный каталог
- /p/<slug>/              — страница библиопункта (по QR-коду)
- /register/, /login/     — читатели
- /org/                   — кабинет организации (Фаза 6)

## Ввод инвентарных номеров
Основной способ — ручной ввод в текстовое поле + Enter или кнопка.
В будущем: USB штрих-код сканер (работает так же — вводит текст + Enter).
Код поддерживает оба варианта без изменений.

## Три типа пользователей
1. Библиотекарь — /admin-panel/ — полный доступ
2. Читатель — публичный каталог + заявки на книги
3. Организация — /org/ — отдельный кабинет (Фаза 6)

## Локализация (RU/UZ)
- Стандартный Django i18n: `{% translate %}` / `{% blocktranslate %}` в шаблонах,
  `gettext_lazy`/`gettext` в моделях и формах (для `choices=` и списков жанров/языков/типов —
  иначе `{{ form.field }}` рендерит `<select>` в обход шаблонного перевода).
  Переводить `{{ form.field.label }}`/`{{ form.field.help_text }}` и переменные вроде
  `{{ title }}` тоже нужно через `{% translate ... %}` (перевод по значению — безопасно, если
  строки нет в каталоге, тег просто вернёт её как есть).
- Переводы лежат в `locale/uz/LC_MESSAGES/django.po` (русский текст — msgid, его не нужно
  дублировать в `locale/ru/...`, т.к. `LANGUAGE_CODE = 'ru'` и исходные строки уже на русском).
- **На Windows GNU gettext обычно не установлен**, поэтому `manage.py compilemessages` не
  работает. Вместо него — `python scripts/compile_locale.py` (чистый Python, через `polib`,
  без системных зависимостей). Запускать после любых правок `.po`.
- `python scripts/check_missing_translations.py` — находит строки в `{% translate "..." %}` /
  `{% blocktranslate %}`, которых ещё нет в `django.po`. Полезно после добавления новых
  шаблонов/строк.

## Акты доставки (PDF и Word)
- `apps/deliveries/act_data.py` — общее содержимое акта (на текущем языке RU/UZ), `pdf_utils.py` — ReportLab, `docx_utils.py` — python-docx.
- Шрифт DejaVu Sans лежит в `apps/deliveries/fonts/` (кириллица + узбекская латиница) — ни системные шрифты, ни GTK/WeasyPrint не нужны, работает на Windows и Linux.
